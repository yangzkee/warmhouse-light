# 学生代码复制速查手册（LIGHT / STM32G071 巡线工程）

本文档供实验课 **直接复制粘贴** 使用。复制前请先阅读 **[复制规则](#复制规则)**，避免覆盖 CubeMX 生成区导致编译失败。

---

## 复制规则

1. **只改 `/* USER CODE BEGIN … */` 与 `/* USER CODE END … */` 之间的代码**（除非老师明确要求改别处）。
2. 用 **STM32CubeMX 重新生成代码** 后，若提示冲突，**保留 USER 区内**你改过内容。
3. 本手册中的片段需与 **`Core/Src`、`Core/Inc`** 里**当前工程**一致；若你本地改过引脚/波特率，以 **Keil 能编译通过的源码** 为准。
4. **`printf` 不要接到 USART1**（底盘 Dcar 协议）；调试串口用 **LPUART1**（代码里宏名 `huart3` 指向 `hlpuart1`）。

---

## 1. `main.h`：类型别名 + `huart3` 宏（USER CODE EM / ET）

粘贴到 **`main.h`** 的 `USER CODE BEGIN ET` / `USER CODE END ET` 与 `USER CODE BEGIN EM` / `USER CODE END EM`：

```c
/* USER CODE BEGIN ET */
typedef uint8_t u8;
typedef uint16_t u16;
typedef uint32_t u32;
typedef int8_t s8;
typedef int16_t s16;
typedef int32_t s32;
/* USER CODE END ET */
```

```c
/* USER CODE BEGIN EM */
#define huart3 hlpuart1
/* USER CODE END EM */
```

## 3. `main.c`：开关宏（USER CODE PD）

```c
/* USER CODE BEGIN PD */
#define USE_LINE_TRACKING 1
#ifndef USE_USART3
#define USE_USART3  1
#endif
#ifndef MAIN_STARTUP_DELAY_MS
#define MAIN_STARTUP_DELAY_MS  8000u
#endif
/* USER CODE END PD */
```

| 宏 | 含义 |
|----|------|
| `USE_LINE_TRACKING` | `1`：主循环里跑 `LineTracking_Step()`；`0`：自行写逻辑 |
| `USE_USART3` | `1`：初始化 **LPUART1** 调试口（宏名历史原因叫 USART3）；`0`：不初始化 |
| `MAIN_STARTUP_DELAY_MS` | 上电后延时再跑主循环，方便插串口；调试完可改 `0` |

## 4. `main.c`：串口接收缓冲（USER CODE PV）

```c
/* USER CODE BEGIN PV */
uint8_t aRxBuffer1; /* USART1：Dcar */
uint8_t aRxBuffer2; /* USART2：灰度 */
#if USE_USART3
uint8_t aRxBuffer3; /* LPUART1 调试 */
#endif
/* USER CODE END PV */
```

## 5. `main.c`：标准输出不重定向到 USART1（USER CODE 0 片段）

保持 **`APP_STDIO_UART` 为 0** 时，`printf` 不会往串口打（避免破坏 Dcar）。若要用 `printf` 到调试口，在 **`#ifndef APP_STDIO_UART` 前** 或工程选项里定义：

```c
#define APP_STDIO_UART  0   /* 推荐：不接调试打印 */
/* 若要用 LPUART1 打印，改为 3，且 USE_USART3 必须为 1 */
```

完整 `__io_putchar` / `_write` 与 **`HAL_UART_ErrorCallback`（仅 USART1 清错）**、**`HAL_UART_RxCpltCallback`** 请从仓库 **`main.c`** 中 `USER CODE BEGIN 0` 整段复制，过长此处不重复。

**回调要点（背下来）：**

- `USART1` → `Deal_DF_Usart(aRxBuffer1)` → 再 `HAL_UART_Receive_IT(&huart1, &aRxBuffer1, 1)`
- `USART2` → `Deal_IR_Usart(aRxBuffer2)` → 再 `HAL_UART_Receive_IT(&huart2, &aRxBuffer2, 1)`
- `LPUART1` → 仅重启 `HAL_UART_Receive_IT(&huart3, &aRxBuffer3, 1)`（`huart3` 为宏）

## 6. `main.c`：外设初始化顺序（USER CODE 2 之前）

在 `MX_GPIO_Init()` 之后常用顺序示例：

```c
  MX_GPIO_Init();
  MX_UserLED_GPIO_Init();
  MX_USART1_UART_Init();
  MX_USART2_UART_Init();
#if USE_USART3
  MX_LPUART1_UART_Init();
#endif
  MX_I2C1_Init();
```

> `MX_UserLED_GPIO_Init()` 在 **`gpio.c` USER 区** 实现；若未添加，需自己写 PC13 或改为板载 LED 引脚。

## 7. `main.c`：启动接收与巡线初始化（USER CODE 2）

```c
  /* USER CODE BEGIN 2 */
  HAL_UART_Receive_IT(&huart1, &aRxBuffer1, 1);
  HAL_UART_Receive_IT(&huart2, &aRxBuffer2, 1);
#if USE_USART3
  HAL_UART_Receive_IT(&huart3, &aRxBuffer3, 1);
#if DEBUG_ODOM_UART_ENABLE
  DebugUsart3_BootPing();
#endif
#endif

  System_Init();
  Odom_Init();

  HAL_Delay(100);
  IR_Send_Control_Data(0, 0, 1);
  HAL_Delay(50);

#if USE_LINE_TRACKING
  NavOdom_SetProfile(NAV_ODOM_PROFILE_DEFAULT);
  LineTracking_Init();
#endif
  HAL_Delay(MAIN_STARTUP_DELAY_MS);
  /* USER CODE END 2 */
```

## 8. `main.c`：主循环（USER CODE 3）

```c
    /* USER CODE BEGIN 3 */
#if USE_LINE_TRACKING
    LineTracking_Step();
#endif
    HAL_Delay(LINE_TRACK_LOOP_MS);
    /* USER CODE END 3 */
```

`LINE_TRACK_LOOP_MS` 在 **`LineTracking.h`** 中定义，默认 **4**（单位 ms）。

## 9. `main.c`：TIM7 滴答（USER CODE 4）

若工程用 **TIM7** 做 HAL 时基，保留：

```c
/* USER CODE BEGIN 4 */

extern TIM_HandleTypeDef htim7;

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM7)
  {
    HAL_IncTick();
  }
}

/* USER CODE END 4 */
```

## 11. `gpio.c`：PC13 用户灯（USER CODE 2 示例）

与 `DF_Communication.c` 里 `LED_Set` 使用 **GPIOC PIN_13** 时配套：

```c
/* USER CODE BEGIN 2 */
void MX_UserLED_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};
  GPIO_InitStruct.Pin = GPIO_PIN_13;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
  HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_SET);
}
/* USER CODE END 2 */
```

并在 **`MX_GPIO_Init`** 里增加：`__HAL_RCC_GPIOC_CLK_ENABLE();`

## 12. 手动发速度（测试底盘是否通）

在 **`DF_Communication.h`** 已声明。测试时可在 **`USER CODE 3`** 里**临时**写（注意与巡线冲突，建议 `USE_LINE_TRACKING 0` 时再试）：

```c
sendVel(0.0f, 0.15f, 0.0f);  /* Vx, Vy, Vz；具体单位见协议与 SCALE */
HAL_Delay(200);
```

常用接口：

```c
void sendVel(float V_x, float V_y, float V_z);
void requestOdomData(void);
```

## 13. 读取 8 路灰度（调试用）

在任意能编译到的 `.c` 里包含 **`ir_grayscale.h`**：

```c
extern u8 IR_Data_number[IR_NUM];  /* IR_NUM=8 */
```

数组下标 **0 最左、7 最右**；**0=黑、1=白**（数字模式）。

## 14. 波特率与引脚（与当前 `usart.c` 一致时可直接填实验报告）

| 外设 | 波特率 | MCU 引脚（默认 Cube 配置） |
|------|--------|----------------------------|
| USART1 底盘 | 以 `usart.c` 为准（常见 460800） | PA9 TX，PA10 RX |
| USART2 灰度 | 115200 | PA2 TX，PA3 RX |
| LPUART1 调试 | 以 `usart.c` 为准（常见 460800） | PB11 TX，PB10 RX |

接线：**TX 接对方 RX**，**GND 共地**。

## 15. 关闭巡线、只保留闪烁灯（最小骨架）

`USER CODE PD`：

```c
#define USE_LINE_TRACKING 0
```

`USER CODE 3`：

```c
    LED_Set(1);
    HAL_Delay(200);
    LED_Set(0);
    HAL_Delay(200);
```

需已正确实现 **`LED_Set`**（`DF_Communication.c`）与 **`MX_UserLED_GPIO_Init`**。

- [ ] Keil **Rebuild**，0 Error。
